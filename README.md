# Квадратный корень — разбор РГР

Учебный сайт по математическому анализу: методы Герона, Бакхшали и метод с двумя переменными.

**Сайт:** https://bortulev-coder.github.io/square-root/

## Что внутри

- Доказательства всех девяти пунктов задания, пояснения терминов и графики.
- Интерактивная лаборатория с точностью 180 значащих цифр и экспортом CSV.
- Полный исходный Python-файл: все 204 строки с объяснением смысла, синтаксиса, порядка выполнения и блока.
- Режим последовательного чтения всех пояснений и печати.
- Построчный разбор вывода консоли, таблиц JSON, проверок и кода завершения.
- Вопросы к защите и задания для самопроверки.

## Открыть локально

Откройте `index.html` в современном браузере. Сборка и установка JavaScript-зависимостей не нужны. Шрифты, KaTeX и Decimal.js включены в репозиторий.

## Запустить Python

Нужен Python 3.10 или новее. Из корня репозитория:

```bash
python -m pip install matplotlib
python downloads/sqrt_experiments.py
```

Результаты появятся в `downloads/sqrt_results/` рядом с Python-файлом: шесть рисунков в PNG и SVG, `iterations.csv` и `summary.json`. Численные проверки выполняются автоматически. Окна графиков не открываются: программа сохраняет изображения в файлы.

## Публикация

GitHub Pages: ветка `main`, папка `/ (root)`. Файл `.nojekyll` отключает обработку Jekyll. Все ссылки на ресурсы относительные, поэтому сайт работает по адресу репозитория.
