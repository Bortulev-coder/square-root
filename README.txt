КВАДРАТНЫЙ КОРЕНЬ — ПОДРОБНЫЙ РАЗБОР РГР

Откройте index.html в современном браузере. Сайт работает без установки,
сборки и подключения к интернету. Все шрифты и библиотеки включены.

Разделы
  Разбор РГР: шесть глав, доказательства всех девяти пунктов задания,
  объяснения обозначений и терминов, таблицы и исходные графики.
  Эксперимент: три метода, изменяемые параметры, графики, выбор шага, CSV.
  Весь код: исходные 204 строки Python без сокращений; для каждой строки
  объяснены её смысл, порядок выполнения, имена и конструкции Python.
  «Читать все 204 строки подряд» — полный открытый текст для чтения и печати.
  Консоль: все 68 строк примера запуска с объяснением каждого поля JSON,
  чисел в таблицах, проверки, кода завершения и файлов результатов.
  К защите: 22 вопроса с ответами, поиск и шесть заданий самопроверки.
  Материалы: условие, отчёт, программа, данные.

Просмотрщик кода
  Выберите полный файл или тематическую выборку его строк.
  Нажмите строку: справа появятся её объяснение и смысл всего блока.
  Можно ввести номер, пользоваться кнопками Пред./След. или клавишами
  вверх/вниз. Home и End переходят к первой и последней строкам.
  Ссылка в адресной строке сохраняет выбранные файл и номер строки.
  Короткие представления предназначены для изучения; для запуска
  скачивайте полный файл downloads/sqrt_experiments.py.

Запуск расчётов Python (версия 3.10 или новее)
  python -m pip install matplotlib
  python sqrt_experiments.py
  Результаты появятся в папке sqrt_results рядом с программой.

Структура сайта
  index.html     оболочка и подключение файлов
  style.css      оформление и адаптация к ширине экрана
  app.js         навигация, просмотрщик, графики и интерактивные элементы
  engine.js      вычисления трёх методов с точностью 180 значащих цифр
  content.js     теория, вопросы и задания самопроверки
  programs.js    исходные строки Python и пояснения к ним
  console-data.js полный пример вывода с построчными объяснениями
  downloads/    исходное задание, отчёт, Python, CSV, JSON
  figures/      шесть векторных графиков из отчёта
  vendor/       локальные шрифты, KaTeX 0.16.22, Decimal.js 10.6.0

Размещение на GitHub Pages
  Загрузите содержимое этой папки в корень репозитория.
  В Settings / Pages выберите Deploy from a branch, свою ветку
  и папку / (root). После публикации откройте адрес, показанный GitHub.
  Ссылки на ресурсы относительные: сайт работает в подпапке репозитория.

Расчёт и точность
  Эталон sqrt используется только для измерения ошибки в эксперименте.
  Рекуррентные формулы сами не вызывают готовую функцию извлечения корня.
  Отображаемые числа округлены, экспорт CSV сохраняет вычисленные цифры.
  Нулевая вычисленная ошибка может означать достижение точности арифметики.
  Численные проверки служат контролем программы и не заменяют доказательства.
